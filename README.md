# jumpipgo.github.io

Служебный репозиторий сайта. **Исходников МЕЗО здесь нет** — они приватны, в
репозитории `jumpipgo/TREN`.

Здесь лежит всё, что должно обслуживаться GitHub Pages:

| путь | что это |
|---|---|
| `index.html` | корневая страница сайта со ссылкой на приложение |
| `README.md` | этот файл |
| `.nojekyll` | чтобы Pages не трогал файлы с подчёркиваниями |
| `TREN/` | собранное приложение целиком — то, что отдаётся по `https://jumpipgo.github.io/TREN/` |
| `TREN/BUILD` | sha исходников, из которых собрано то, что сейчас на проде |
| `.well-known/assetlinks.json` | цифровые ссылки для TWA: связывают домен и подпись APK |

## Откуда берётся содержимое

Только выкладкой из исходников: `npm run deploy` в `jumpipgo/TREN`. Скрипт
собирает, копирует `dist/` в `TREN/`, пишет маркер, сверяет имя бандла и
проверяет, что прод соответствует коммиту из `origin/main`, — и только потом
делает `git add -A`, коммит и пуш сюда.

**Руками сюда ничего не копируется.** В `TREN/assets/` копится десятки старых
сборок, поэтому «самая свежая по дате» и glob по имени здесь врут: сверить
можно только точным именем бандла.

Пуш в этот репозиторий запускает Pages — публикация автоматическая, отдельного
действия не нужно.
